¿Qué es este documento?

Crossref recibe un archivo XML con datos de la revista, del número y de cada artículo. Este documento lista cada tipo de dato que suele incluirse (como en los envíos hechos desde plataformas editoriales habituales) y señala si el Administrador de DOIs de [in]genios puede crearlo hoy.

Cómo leerlo: abra cada sección con un clic para ver el detalle técnico. Use los filtros arriba para acotar la lista. Para una lista sencilla (sin códigos XML) con lo automático vs. manual y qué ya trae el XML maestro de Ingenio, pulse Vista previa sencilla.
